# goproteen

Interactive 3D Website and Cellular Nutrition Experience for GoProteen.

## Features
- **Interactive 3D Anatomy & Skeletal Experience**: Explore joint density, spinal column, hips, and knees with real-time 3D camera navigation.
- **Dynamic 3D Femur Bone Density Simulation**: Continuous age progression (30 to 60) demonstrating cortical vs trabecular porosity changes.
- **Cellular & Muscle Remodeling Visualizer**: Interactive muscle fascicle and amino acid dynamics.
- **Audio Narration**: Immersive audio storytelling synchronized with interactive steps.

## Tech Stack
- Next.js (App Router)
- React Three Fiber / Three.js
- Tailwind CSS
- Lucide React
